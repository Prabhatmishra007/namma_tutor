Section E · Case study · 4 marks
14.A hall has 20 rows of seats. The first row has 20 seats, the second row has 22 seats, the third row has 24 seats, and so on — each row having 2 more seats than the one before it.[4]
This is a classic real-world AP setup — the seat counts per row form an arithmetic progression with a = 20, d = 2.
(i) Write the AP formed by the number of seats in each row.  [1]
(ii) How many seats are there in the 15th row?  [1]
(iii) Find the total number of seats in the hall (all 20 rows).  [2]
