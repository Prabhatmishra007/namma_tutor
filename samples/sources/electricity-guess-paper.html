Section A

Section B
6. Drift velocity = average velocity gained by electrons against the field, between collisions. I = nAevd  [1: definition, 1: formula]
7. R = 2+3+4 = 9Ω. I = V/R = 9/9 = 1 A
8. Potentiometer compares EMFs using a balance-point on a uniform wire, drawing zero current from the cell at balance — so it measures true EMF, unlike a voltmeter which always draws some current and reads terminal voltage, not EMF.
Section C
9. Same voltage V across each; total current I = I1+I2+I3 = V/R1+V/R2+V/R3. Since I=V/R_eq: 1/R_eq = 1/R1 + 1/R2 + 1/R3
10. (a) I = ε/(R+r) = 12/6 = 2 A
(b) V = ε − Ir = 12 − 4 = 8 V
11. Junction rule (ΣI=0) → conservation of charge. Loop rule (ΣΔV=0) → conservation of energy.
Section D
12. Treating the parallel combination as a single cell: ε_eq = (ε1r2 + ε2r1)/(r1+r2),   1/r_eq = 1/r1 + 1/r2. Derived from equating terminal voltage expressions for both branches and applying charge conservation at the junction.
13. Apply loop rule to both loops and junction rule at the node; solve the resulting simultaneous equations for the three branch currents. (Full numeric working shown in the complete answer key, with the labelled circuit diagram.)
Section E — Case Study
14.
(i) Balance condition: P/Q = R/S
(ii) 10/20 = 15/S → S = 15×20/10 = 30 Ω
(iii) Comparable arm values give the galvanometer deflection maximum sensitivity to small changes near balance — very unequal arms make the null point hard to detect precisely.
